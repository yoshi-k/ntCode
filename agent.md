# Agent Overview — LinguAPI

Welcome. This file is your starting point for understanding the LinguAPI project.

## What is LinguAPI?
LinguAPI is a tool that leverages LLMs to help developers understand and navigate unfamiliar codebases. It supports two core use cases:
1. Finding where a specific functionality is implemented.
2. Understanding what a specific file or function does.
